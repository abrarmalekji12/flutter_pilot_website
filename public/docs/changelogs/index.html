FlutterPilot 2.0.0

A major reliability-focused update that makes the supported FlutterPilot workflow stronger from AI generation and visual editing through data, app logic, preview, export, and web publishing.

Version 2.0.0 October 5, 2026
Major release

What’s new

October 5, 2026

Smarter Starter App generation

Generate editable, Collection-backed starter apps with clearer list, details, add, edit, delete, and navigation workflows—built to be extended inside the Studio.

Safer AI editing and orchestration

The AI Assistant now uses more structured task planning for supported create/edit work, with stronger target validation and safer handling of failed or no-change operations.

More capable Action Flows

Action execution is more consistent across the editor, Run, and export, with typed reusable Events, typed trigger values, and improved Widget State access inside flows.

Richer data queries and bindings

Collection workflows now support stronger structured queries, including nested all/any conditions, null checks, IN-style filters, ordered multi-sort, and more reliable row-scoped bindings.

Stronger export reliability

Export now applies stricter type-aware validation and better Preview/Export parity for page arguments, Save Record values, callback values, and other typed destinations—reducing invalid generated Dart.

Improved web publishing

Hosted web apps are easier to manage from Export & Deploy, including the ability to unpublish a live site without deleting the FlutterPilot project.

Editor stability improvements

2.0 includes fixes for large-project opening performance, binding-picker crashes, component search edge cases, and several preview/runtime consistency issues.

More predictable AI failures

Deterministic AI/request failures stop retrying unnecessarily, helping prevent retry loops and making unsuccessful operations fail more clearly instead of appearing to hang.

Release scope: FlutterPilot 2.0 prioritizes dependable Starter App and core editor workflows. Broader Functional App generation remains limited while its end-to-end reliability work continues.
