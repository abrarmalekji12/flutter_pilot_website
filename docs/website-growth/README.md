## Evidence limits

- The Search Console coverage export dated 2026-10-27 was **not available** to this investigation. The latest coverage data used is the 2026-10-19 aggregate in Issue #12.
- `flutterpilot.com` and `studio.flutterpilot.com` were blocked by the investigation environment's network policy. Production facts come from GitHub Actions logs (2026-10-27 deploy run) and source code.
- Competitor facts come from web search results, mostly third-party. Re-verify them on official pages before publishing.
